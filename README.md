# 🪄 MagiciansWEB

Página web oficial de **Magician Tech** (proyecto discontinuado).

---

## 📌 Descripción

Este repositorio contiene el código de la página web corporativa desarrollada para **Magician Tech**, una empresa que **actualmente ya no existe**.

El proyecto se conserva como referencia técnica y parte del historial de desarrollo del equipo.

---

## 🧱 Tecnologías

- **Angular** (Frontend)
- HTML / CSS / TypeScript
- Node.js (entorno de desarrollo)

---

## 🚧 Estado del proyecto

⚠️ **sin mantenimiento activo**

Magician Tech dejó de operar, por lo tanto este sitio no se encuentra en desarrollo ni actualización.
